# routes/

Reference routes the page can load with `&r=<name>` in the link, served as
`routes/<name>.gpx`. Names may contain letters, digits, `.`, `_` and `-` only.

To add one from the phone: open this folder on github.com, tap **Add file →
Upload files**, pick the GPX from Files, commit to `main`. A minute later
`https://dominyko-labs.github.io/hike-map/#...&r=<name>` draws it.

There is no Alta Via 1 GPX checked in here because none could be fetched from
the build environment. Use the **Alta Via 1 from OSM** button on the page, or
upload a GPX you trust (a guidebook download, or the export from a hiking app).
